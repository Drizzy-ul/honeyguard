Domain 1.0: General Security Concepts & Deception Technologies

Honeypots & Decoys: A honeypot is a deliberate, vulnerable decoy system designed to deceive attackers, detect unauthorized access, and capture attacker TTPs (Tactics, Techniques, and Procedures) without endangering production systems.

Domain 2.0: Threats, Vulnerabilities & Mitigations

  • T1110 Brute Force & Credential Stuffing: Automated dictionary attacks against SSH (port 22/2222) and Web admin portals.
  • T1190 Exploit Public-Facing Application: SQL Injection, Path Traversal, and Log4Shell payload injections.
  • T1083 File & Directory Discovery: Probing for /.env, /.git/config, and backup files.
  • T1059 Command & Scripting Interpreters: Shell commands used to download droppers (wget, curl | bash).

Domain 4.0: Security Operations & SIEM Log Analysis

HoneyGuard generates structured JSONL event streams matching modern SIEM parsers (Splunk, Elastic SIEM, Microsoft Sentinel) for correlation and IoC hunting.

Incident Response (IR) Playbook
  1. 1. Preparation: Deploy low-interaction decoy sensors across DMZ and internal VLANs to catch lateral movement.
  2. 2. Detection & Analysis: Extract source IPs, User-Agents, and intercepted credential payloads. Identify whether the attack is opportunistic (botnet) or targeted.
  3. 3. Containment: Export captured high-risk adversary IPs and apply immediate firewall / ACL ban rules or cloud security group blocks.
  4. 4. Eradication: Inspect downloaded dropper URLs and hashes (e.g. wget http://malware...) and block domains at the DNS/Proxy level.
  5. 5. Post-Incident Review: Add newly uncovered passwords and usernames to corporate password blocklists (Active Directory Fine-Grained Password Policies).
